# IP-SHAKTI-Sahayak-Prototype
A jurisdiction-segregated, RAG-grounded IPR assistant for Ayurveda that enforces formulation-aware classification, ABS/GRATK compliance, and mandatory source citations. It reduces mis-filing and biopiracy risk, accelerates patent/export readiness, and aligns with DPDP guardrails via multilingual, citation-traceable guidance with human escalation.
